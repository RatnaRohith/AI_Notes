UNIFICATION AND LIFTING IN ARTIFICIAL INTELLIGENCE

1. INTRODUCTION

In Artificial Intelligence, especially in First-Order Logic (FOL) and Logic Programming, we often need to determine whether two logical expressions can be made identical by assigning suitable values to their variables.

This process is called Unification.

Lifting is a technique used in logical inference to perform reasoning at the general first-order logic level instead of generating all possible ground instances.

--------------------------------------------------

2. UNIFICATION

Definition:

Unification is the process of finding substitutions for variables that make two or more logical expressions identical.

The substitution that makes the expressions identical is called a Unifier.

Example:

Consider the expressions:

P(x, a)

P(b, a)

To make them identical, substitute b for x.

Substitution: θ = {x/b}

After substitution:

P(b, a) = P(b, a)

Therefore, {x/b} is a unifier.

--------------------------------------------------

3. SUBSTITUTION

A substitution is an assignment of terms to variables in a logical expression.

Example:

θ = {x/John, y/Mary}

Consider:

Likes(x, y)

After applying the substitution:

Likes(John, Mary)

Notation:

x/John means replace the variable x with the term John.

--------------------------------------------------

4. EXAMPLES OF UNIFICATION

Example 1: Unifying a Variable and a Constant

Expressions:

P(x)

P(a)

Substitution:

θ = {x/a}

After substitution, both expressions become P(a).

Therefore, unification succeeds.

Example 2: Unifying Two Expressions with Multiple Arguments

Expressions:

P(x, y)

P(a, b)

Substitution:

θ = {x/a, y/b}

Both expressions become P(a, b).

Example 3: Unifying Expressions with Different Variables and Constants

Expressions:

Knows(x, John)

Knows(Mary, y)

Compare the corresponding arguments:

x = Mary

y = John

Therefore:

θ = {x/Mary, y/John}

Both expressions become:

Knows(Mary, John)

--------------------------------------------------

5. UNIFICATION WITH FUNCTIONS

Unification can also involve function terms.

Example:

P(f(x), x)

P(f(a), a)

Compare the arguments:

x = a

The first argument also requires f(x) = f(a), which is satisfied by x = a.

Therefore:

θ = {x/a}

After substitution, both expressions become:

P(f(a), a)

Hence, unification succeeds.

--------------------------------------------------

6. WHEN UNIFICATION FAILS

Unification is not possible in every situation.

Case 1: Different Predicate Names

P(x)

Q(x)

Unification fails because P and Q are different predicate symbols.

Case 2: Different Constants

P(a)

P(b)

Unification fails if a and b are distinct constants.

Case 3: Different Numbers of Arguments

P(x)

P(x, y)

Unification fails because the predicates have different arities.

Arity means the number of arguments accepted by a predicate or function.

--------------------------------------------------

7. MOST GENERAL UNIFIER (MGU)

Definition:

The Most General Unifier (MGU) is a unifier that imposes the fewest restrictions on the variables while making the expressions identical.

Example:

P(x)

P(y)

A most general unifier is:

θ = {x/y}

After substitution:

P(y)

P(y)

The MGU does not unnecessarily replace the variables with a specific constant.

Importance of MGU:

1. It keeps logical expressions as general as possible.
2. It avoids unnecessary restrictions on variables.
3. It supports efficient automated reasoning.
4. It is important in resolution and logic programming.

--------------------------------------------------

8. UNIFICATION ALGORITHM

The basic steps of unification are:

Step 1: Compare Predicate or Function Symbols

The symbols must match.

For example:

P(x) and P(a) can potentially be unified.

P(x) and Q(a) cannot be unified.

Step 2: Compare the Number of Arguments

The expressions must have the same number of arguments.

For example:

P(x, y) and P(a, b) have two arguments each.

Step 3: Compare Corresponding Arguments

Consider:

P(x, f(y))

P(a, f(b))

Compare the first arguments:

x = a

Compare the second arguments:

f(y) = f(b)

Therefore:

y = b

The resulting substitution is:

θ = {x/a, y/b}

Step 4: Apply the Substitution

After applying the substitution, both expressions become:

P(a, f(b))

Therefore, unification succeeds.

--------------------------------------------------

9. OCCURS CHECK

Definition:

The Occurs Check is a test used during unification to prevent a variable from being unified with a term containing that same variable.

Example:

x

f(x)

Attempting to unify them requires:

x = f(x)

This would create a recursive or infinite term:

x = f(f(f(f(...))))

In standard finite-term first-order logic, this unification fails.

Therefore, the occurs check prevents invalid substitutions of this kind.

--------------------------------------------------

10. STEP-BY-STEP UNIFICATION EXAMPLE

Consider:

Knows(x, f(y))

Knows(John, f(Mary))

Step 1: Compare the Predicate Names

Knows = Knows

The predicate names match.

Step 2: Compare the First Arguments

x = John

Therefore:

x/John

Step 3: Compare the Second Arguments

f(y) = f(Mary)

Since the function symbols are identical:

y = Mary

Therefore:

y/Mary

Step 4: Write the Final Substitution

θ = {x/John, y/Mary}

After applying the substitution, both expressions become:

Knows(John, f(Mary))

Hence, the expressions are successfully unified.

--------------------------------------------------

11. IMPORTANCE OF UNIFICATION IN AI

Unification is an important operation in Artificial Intelligence.

Applications include:

1. First-Order Logic
2. Automated Theorem Proving
3. Resolution
4. Logic Programming
5. Prolog
6. Expert Systems
7. Knowledge Representation
8. Natural Language Processing
9. Automated Reasoning

Example in Prolog:

Fact:

likes(john, pizza).

Query:

likes(john, X).

The variable X is unified with pizza.

Result:

X = pizza

Thus, unification allows Prolog to find values that satisfy a query.

--------------------------------------------------

12. LIFTING

Definition:

Lifting is the process of performing logical inference at the general first-order logic level using variables and substitutions instead of generating all possible ground instances.

A ground expression is a logical expression that contains no variables.

Example:

General Rule:

Human(x) → Mortal(x)

Fact:

Human(Socrates)

Using the general rule and the fact, we infer:

Mortal(Socrates)

Unification matches Human(x) with Human(Socrates) using the substitution:

θ = {x/Socrates}

The inference is performed directly using the general rule.

This is an example of lifted inference.

--------------------------------------------------

13. GROUND-LEVEL REASONING VS LIFTED REASONING

A. Ground-Level Reasoning

Ground expressions contain no variables.

Examples:

Human(Socrates) → Mortal(Socrates)

Human(John) → Mortal(John)

Human(Mary) → Mortal(Mary)

If there are many individuals, we may need to generate many specific instances of a general rule.

B. Lifted Reasoning

Instead of generating individual rules, we retain the general rule:

Human(x) → Mortal(x)

When a fact is available:

Human(Socrates)

We use unification to determine the substitution:

θ = {x/Socrates}

Then we infer:

Mortal(Socrates)

Advantages of Lifted Reasoning:

1. It avoids unnecessary generation of ground instances.
2. It allows reasoning with variables.
3. It represents general knowledge compactly.
4. It supports efficient first-order inference.

--------------------------------------------------

14. LIFTING IN RESOLUTION

Lifting is particularly important in First-Order Logic Resolution.

Consider the clauses:

C₁: P(x) ∨ Q(x)

C₂: ¬P(a) ∨ R(a)

The complementary literals are:

P(x) and ¬P(a)

These literals can be unified using:

θ = {x/a}

Apply the substitution to the clauses:

C₁: P(a) ∨ Q(a)

C₂: ¬P(a) ∨ R(a)

Resolve P(a) against ¬P(a).

The resulting resolvent is:

Q(a) ∨ R(a)

This is an example of lifted resolution, in which unification is used to perform inference between first-order clauses.

--------------------------------------------------

15. LIFTING THEOREM

Definition:

The Lifting Theorem states, in the context of resolution, that a ground-level resolution inference can be represented by a corresponding first-order resolution inference using a suitable unifier.

In simple terms:

Ground-level inference can be represented by a more general first-order inference.

The theorem is important because it shows that first-order resolution can reason with variables without requiring the explicit generation of every possible ground instance.

--------------------------------------------------

16. EXAMPLE OF LIFTING USING RESOLUTION

Given the knowledge base:

Human(x) → Mortal(x)

Human(Socrates)

Step 1: Convert the Implication into Clause Form

Using the logical equivalence:

P → Q ≡ ¬P ∨ Q

We obtain:

¬Human(x) ∨ Mortal(x)

The second clause is:

Human(Socrates)

Step 2: Identify the Complementary Literals

¬Human(x)

Human(Socrates)

Step 3: Find the Unifier

Unify:

Human(x)

Human(Socrates)

The substitution is:

θ = {x/Socrates}

Step 4: Apply the Substitution

The first clause becomes:

¬Human(Socrates) ∨ Mortal(Socrates)

The second clause is:

Human(Socrates)

Step 5: Apply Resolution

The complementary literals cancel:

¬Human(Socrates)

Human(Socrates)

The resulting clause is:

Mortal(Socrates)

Therefore:

Mortal(Socrates)

This demonstrates how unification supports lifted inference in first-order logic.

--------------------------------------------------

17. RELATIONSHIP BETWEEN UNIFICATION AND LIFTING

Substitution:

Replacing variables with terms.

Unification:

Finding substitutions that make logical expressions identical.

Most General Unifier (MGU):

The most general substitution that makes expressions identical.

Ground Inference:

Performing reasoning using expressions without variables.

Lifting:

Performing the corresponding inference at the general first-order level.

Lifted Resolution:

Applying resolution to first-order clauses using unification.

Key Relationship:

UNIFICATION ENABLES LIFTED INFERENCE.

Unification identifies matching expressions, while lifting allows the inference to be carried out at the general first-order level.

19. IMPORTANT EXAMPLE FOR STUDENTS

Question:

Find a unifier for the following expressions:

Likes(x, IceCream)

Likes(Ravi, y)

Solution:

Compare the first arguments:

x = Ravi

Compare the second arguments:

IceCream = y

Therefore, the substitution is:

θ = {x/Ravi, y/IceCream}

After applying the substitution, both expressions become:

Likes(Ravi, IceCream)

Hence, the expressions are successfully unified.

20. QUICK SUMMARY

UNIFICATION

Purpose: To make logical expressions identical.

Method: Find suitable substitutions for variables.

Result: A unifier, preferably the MGU.

LIFTING

Purpose: To perform inference at the general first-order level.

Method: Use variables, substitutions, and unification.

Result: General first-order inference without explicitly generating every possible ground instance.

KEY POINTS TO REMEMBER

1. Unification = Make expressions match.
2. Substitution = Replace variables with terms.
3. MGU = The most general substitution that makes expressions match.
4. Occurs Check = Prevent a variable from being unified with a term containing itself.
5. Lifting = Perform inference at the general first-order level.
6. Lifted Resolution = Apply resolution using unification.
7. Unification is a key mechanism that enables lifted inference.

FINAL CONCLUSION

Unification and lifting are fundamental concepts in Artificial Intelligence.

Unification helps identify matching logical expressions by finding suitable substitutions. Lifting uses these substitutions to perform inference at the first-order level without explicitly generating all possible ground instances.

Together, they support efficient automated reasoning, first-order resolution, logic programming, and theorem proving.
