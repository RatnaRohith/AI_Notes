Reinforcement Learning
1. Introduction

Reinforcement Learning (RL) is a type of machine learning in which an agent learns how to make decisions by interacting with an environment.

The agent does not receive labeled training examples like supervised learning. Instead, it learns from rewards and penalties received after taking actions.

Simple idea

Try an action → observe the result → receive a reward/penalty → learn whether the action was good or bad → improve future decisions.

Example: Robot Learning to Walk
Agent: Robot
Environment: Ground/world
Action: Move a leg
State: Current position and posture
Reward: +10 for moving forward successfully
Penalty: −10 for falling
Goal: Learn a sequence of movements that maximizes total reward.

4. Environment

The environment is everything outside the agent that the agent interacts with.

Example: Chess
Agent = Chess AI
Environment = Chess board + opponent

The environment changes according to the agent's actions and possibly the actions of other agents.

5. State

A state represents the current situation of the environment from the agent's perspective.

For example, in a game:

State =
Player position
+ Enemy positions
+ Health
+ Ammunition
+ Available weapons

For a robot:

State =
Position
+ Velocity
+ Orientation
+ Sensor readings

We can represent a state as:

$$ S_t $$

where \(t\) represents the current time step.

6. Action

An action is a decision that the agent can take.

For example, in a game:

Move Forward
Move Backward
Turn Left
Turn Right
Attack
Defend

Actions can be:

Discrete actions

A finite set of choices:

$$ A = \{Left, Right, Forward, Backward\} $$
Continuous actions

Actions represented by continuous values.

Example:

Steering = -1.0 to +1.0
Acceleration = 0.0 to 1.0

Continuous actions are common in robotics and vehicle control.

7. Reward

The reward provides feedback to the agent.

It tells the agent how desirable the result of an action was.

Rewards can be:

Positive
Negative
Zero

Example:

Action	Result	Reward
Move toward goal	Good	+10
Move away	Bad	−5
Reach goal	Excellent	+100
Do nothing	Neutral	0
Crash	Very bad	−100

The agent's objective is:

Maximize the cumulative reward over time.

8. Policy

A policy defines how the agent chooses an action given a state.

It can be represented as:

$$ \pi(a|s) $$

which means:

Probability of selecting action \(a\) when the agent is in state \(s\).

For example:

State: Enemy is nearby

Policy:
    Attack → 70%
    Run    → 20%
    Hide   → 10%

A deterministic policy might simply be:

Enemy nearby → Attack
9. Value Function

The value function estimates how good it is for an agent to be in a particular state.

It considers future rewards, not just the immediate reward.

$$ V(s) $$

means:

Expected cumulative future reward when starting from state \(s\).

Example

Suppose a player is standing near a treasure.

State A → State B → Treasure

Although State A gives no immediate reward, it may have a high value because it can eventually lead to treasure.

10. Q-Value

The Q-value evaluates an action in a particular state.

$$ Q(s,a) $$

It represents:

Expected cumulative future reward when taking action \(a\) in state \(s\).

Example:

State	Action	Q-value
Enemy nearby	Attack	80
Enemy nearby	Run	40
Enemy nearby	Hide	20

The agent will generally choose:

Attack

because it has the highest Q-value.

11. Episode

An episode is one complete sequence of interaction from an initial state to a terminal state.

Example: Game

Another example:

Chess game:
Start → Moves → Checkmate

One chess game can be considered an episode.

12. Return

The return is the total accumulated reward from a state onward.

If rewards are:

+10, +5, -2, +20

then the undiscounted return is:

$$ G_t = 10 + 5 - 2 + 20 = 33 $$

However, future rewards are often discounted.

13. Discount Factor

The discount factor is represented by:

$$ \gamma $$

where:

$$ 0 \leq \gamma \leq 1 $$

It determines how much the agent values future rewards.

The return is:

$$ G_t = R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots $$
Interpretation

If:

$$ \gamma = 0 $$

the agent cares only about immediate rewards.

If:

$$ \gamma \approx 1 $$

the agent strongly considers future rewards.

Example

Suppose:

Immediate reward = 10
Future reward = 100
γ = 0.5

Then:

$$ G = 10 + 0.5(100) $$ $$ G = 60 $$
14. Markov Decision Process

Reinforcement learning is commonly modeled using a Markov Decision Process (MDP).

An MDP can be represented as:

$$ (S,A,P,R,\gamma) $$

where:

\(S\) = Set of states
\(A\) = Set of actions
\(P\) = Transition probabilities
\(R\) = Reward function
\(\gamma\) = Discount factor
Transition

When an agent performs an action:

$$ S_t \xrightarrow{A_t} S_{t+1} $$

The environment moves from the current state to a new state.

The agent receives:

$$ R_{t+1} $$

So the complete interaction is:

$$ (S_t,A_t,R_{t+1},S_{t+1}) $$
15. Exploration vs Exploitation

One of the most important problems in RL is deciding between:

Exploration

Try something new to discover potentially better actions.

Example:

"I normally attack,
but perhaps hiding is better."
Exploitation

Choose the action currently believed to be best.

"Attacking has produced good rewards before,
so I will attack again."

The agent needs to balance both.

16. Epsilon-Greedy Strategy

A common method for balancing exploration and exploitation is ε-greedy.

With probability:

$$ \epsilon $$

the agent chooses a random action.

With probability:

$$ 1-\epsilon $$

it chooses the action with the highest Q-value.

For example:

$$ \epsilon = 0.1 $$

means:

10% → Explore
90% → Exploit
Algorithm
if random number < ε:
    choose random action
else:
    choose action with maximum Q-value
17. Q-Learning

Q-learning is one of the most important model-free reinforcement learning algorithms.

It learns the optimal Q-value:

$$ Q(s,a) $$

The fundamental update equation is:

$$ Q(s,a) \leftarrow Q(s,a) + \alpha [ r+\gamma\max_{a'}Q(s',a') - Q(s,a) ] $$

Where:

Symbol	Meaning
\(s\)	Current state
\(a\)	Current action
\(r\)	Reward
\(s'\)	Next state
\(a'\)	Next action
\(\alpha\)	Learning rate
\(\gamma\)	Discount factor
18. Q-Learning Example

Suppose:

Current state = S1
Action = Move Right
Reward = +10
Next state = S2

Suppose:

$$ Q(S1,Right)=20 $$

and the best Q-value from S2 is:

$$ \max Q(S2,a)=50 $$

Let:

$$ \alpha=0.1 $$ $$ \gamma=0.9 $$

Then:

$$ Q(S1,Right) = 20+ 0.1[10+0.9(50)-20] $$ $$ =20+0.1[35] $$ $$ =23.5 $$

The Q-value is updated from:

$$ 20 \rightarrow 23.5 $$

Thus, the agent learns that this action is more valuable than it previously believed.

19. SARSA

Another important RL algorithm is SARSA.

SARSA stands for:

State → Action → Reward → State → Action

Its update rule is:

$$ Q(s,a) \leftarrow Q(s,a) + \alpha [ r+\gamma Q(s',a')-Q(s,a) ] $$
Difference from Q-Learning

Q-learning:

$$ r+\gamma\max Q(s',a') $$

Uses the best possible next action.

SARSA:

$$ r+\gamma Q(s',a') $$

Uses the action actually selected by the current policy.

Therefore:

Q-learning → off-policy
SARSA → on-policy

29. Basic Reinforcement Learning Cycle

The complete learning process can be summarized as:

             ┌──────────────┐
             │    Agent     │
             └──────┬───────┘
                    │
                 Action
                    ↓
             ┌──────────────┐
             │ Environment  │
             └──────┬───────┘
                    │
             ┌──────┴───────┐
             │              │
          New State       Reward
             │              │
             └──────┬───────┘
                    ↓
             ┌──────────────┐
             │    Agent     │
             │    learns    │
             └──────────────┘

This process is repeated:

$$ \boxed{ State \rightarrow Action \rightarrow Reward \rightarrow New\ State } $$

until the agent learns a good policy.
