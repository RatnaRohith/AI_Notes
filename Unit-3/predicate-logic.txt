Predicate Logic in Artificial Intelligence

Predicate Logic, also called First-Order Predicate Logic (FOL), is a formal language used in AI to represent knowledge about objects, their properties, and relationships between objects.

It is more expressive than Propositional Logic because it can represent individual objects and relationships using predicates and variables.

1. Why Predicate Logic is needed

Consider these statements:

Ram is a student.
Sita is a student.
Every student studies.
Ram likes Sita.

In propositional logic, we might represent them as:

P = Ram is a student
Q = Sita is a student
R = Every student studies

But propositional logic cannot naturally express the general rule:

Every student studies.

Predicate logic can represent it as:

$$ Student(x) \rightarrow Studies(x) $$

where x represents any individual.

2. Basic Components of Predicate Logic

Predicate logic consists mainly of:

Component	Meaning	Example
Constants	Specific objects	Ram, Sita, John
Variables	General objects	x, y, z
Predicates	Properties/relationships	Student(x), Likes(x,y)
Functions	Map objects to objects	FatherOf(x)
Quantifiers	Specify how many objects	∀, ∃
Logical Connectives	Combine statements	∧, ∨, ¬, →, ↔
3. Predicates

A predicate represents a property or relationship.

Unary predicate

Represents a property of one object.

$$ Student(Ram) $$

Meaning:

Ram is a student.

$$ Intelligent(x) $$

Meaning:

x is intelligent.

Binary predicate

Represents a relationship between two objects.

$$ Likes(Ram,Sita) $$

Meaning:

Ram likes Sita.

$$ Parent(Ram,John) $$

Meaning:

Ram is a parent of John.

Ternary predicate

Represents a relationship involving three objects.

$$ Gives(Ram,Book,Sita) $$

Meaning:

Ram gives a book to Sita.

4. Constants

A constant represents a particular object or individual.

Examples:

$$ Ram $$ $$ Sita $$ $$ Hyderabad $$ $$ Car1 $$

For example:

$$ Student(Ram) $$

means that Ram is a student.

5. Variables

A variable represents an unspecified object.

Common variables:

$$ x,\ y,\ z $$

Example:

$$ Student(x) $$

means:

x is a student.

The actual value of x depends on the context.

6. Quantifiers

Quantifiers are one of the most important features of predicate logic.

There are two major quantifiers:

A. Universal Quantifier — ∀
$$ \forall x $$

Read as:

For all x
For every x

Example:

$$ \forall x(Student(x) \rightarrow Studies(x)) $$

Meaning:

Every student studies.

B. Existential Quantifier — ∃
$$ \exists x $$

Read as:

There exists an x
At least one x

Example:

$$ \exists x(Student(x) \land Intelligent(x)) $$

Meaning:

There exists at least one student who is intelligent.

7. Logical Connectives

Predicate logic uses the same basic logical connectives as propositional logic.

AND — ∧
$$ Student(x) \land Intelligent(x) $$

Meaning:

x is a student and x is intelligent.

OR — ∨
$$ Student(x) \lor Teacher(x) $$

Meaning:

x is a student or x is a teacher.

NOT — ¬
$$ \neg Student(x) $$

Meaning:

x is not a student.

IMPLIES — →
$$ Student(x) \rightarrow Studies(x) $$

Meaning:

If x is a student, then x studies.

IF AND ONLY IF — ↔
$$ Student(x) \leftrightarrow Learner(x) $$

Meaning:

x is a student if and only if x is a learner.

8. Examples of Natural Language to Predicate Logic
Example 1

Statement:

All humans are mortal.

Representation:

$$ \forall x(Human(x) \rightarrow Mortal(x)) $$
Example 2

Statement:

Socrates is a human.

$$ Human(Socrates) $$

Therefore:

$$ Human(Socrates) $$

and

$$ \forall x(Human(x) \rightarrow Mortal(x)) $$

allow us to infer:

$$ Mortal(Socrates) $$

This demonstrates how AI can use predicate logic for reasoning and inference.

Example 3

Statement:

Some students are intelligent.

$$ \exists x(Student(x) \land Intelligent(x)) $$
Example 4

Statement:

Every student likes some teacher.

$$ \forall x(Student(x) \rightarrow \exists y(Teacher(y) \land Likes(x,y))) $$

Notice the two quantifiers:

∀x → every student
∃y → at least one teacher
Example 5

Statement:

No student is a teacher.

$$ \forall x(Student(x) \rightarrow \neg Teacher(x)) $$
9. Predicate Logic vs Propositional Logic
Propositional Logic	Predicate Logic
Represents complete propositions	Represents objects and relationships
Less expressive	More expressive
No variables	Uses variables
No quantifiers	Uses ∀ and ∃
Cannot naturally represent relationships	Can represent relationships
P → Q	Student(x) → Studies(x)
Suitable for simple facts	Suitable for knowledge representation
Simple comparison

Propositional Logic:

$$ P = Ram\ is\ a\ student $$

Predicate Logic:

$$ Student(Ram) $$

Predicate logic can generalize:

$$ \forall x(Student(x) \rightarrow Studies(x)) $$

which is difficult to express directly in propositional logic.

10. Predicate Logic in AI

Predicate logic is used in AI for Knowledge Representation and Reasoning.

A knowledge base can contain:

Facts
$$ Human(Socrates) $$
Rules
$$ \forall x(Human(x) \rightarrow Mortal(x)) $$
Inference

From:

$$ Human(Socrates) $$

and:

$$ \forall x(Human(x) \rightarrow Mortal(x)) $$

AI can derive:

$$ Mortal(Socrates) $$

Thus, predicate logic provides a mechanism for representing:

Objects → Properties → Relationships → Rules → Inferences

11. Important Terms for Students

When teaching Predicate Logic, emphasize these terms:

Domain → Constants → Variables → Predicates → Functions → Quantifiers → Connectives → Well-formed formulas → Interpretation → Inference

A useful way to remember the structure is:

$$ \boxed{\text{Predicate Logic = Objects + Relations + Quantifiers + Logic}} $$
Example knowledge representation

Natural language:

All humans are mortal. Socrates is a human. Therefore, Socrates is mortal.

Predicate logic:

$$ \forall x(Human(x)\rightarrow Mortal(x)) $$ $$ Human(Socrates) $$

Therefore:

$$ Mortal(Socrates) $$

This is the fundamental idea behind using Predicate Logic for Knowledge Representation in AI.

Logic Programming in Artificial Intelligence

Logic Programming is a programming paradigm in which a program is written as a collection of facts and rules, and the computer solves problems by performing logical inference.

Instead of specifying how to solve a problem step by step, we specify what is true and what relationships exist.

A simple definition for students:

Logic programming is a programming approach in which knowledge is represented using facts and rules, and answers are obtained through logical reasoning and inference.

1. Basic Idea

A logic program generally contains:

$$ \boxed{\text{Facts + Rules + Queries}} $$

For example:

Facts
parent(ram, sita).
parent(sita, ravi).

These state:

Ram is a parent of Sita.
Sita is a parent of Ravi.
Rule
grandparent(X, Z) :- parent(X, Y), parent(Y, Z).

Meaning:

X is a grandparent of Z if X is a parent of Y and Y is a parent of Z.

Query
grandparent(ram, ravi).

The system reasons from the facts and rule and answers:

true
2. Components of Logic Programming

There are three major components.

1. Facts

Facts represent information that is known to be true.

student(ravi).
teacher(sita).
likes(ravi, ai).

For example:

$$ Student(Ravi) $$

means:

Ravi is a student.

2. Rules

Rules describe relationships or conditions.

Example:

intelligent(X) :- student(X), studies(X).

Meaning:

X is intelligent if X is a student and X studies.

In logical form:

$$ Student(X) \land Studies(X) \rightarrow Intelligent(X) $$
3. Queries

A query asks the system to determine whether something is true.

student(ravi).

The system searches the knowledge base and returns:

true

A query can also contain variables:

student(X).

The system may return:

X = ravi
3. Logic Programming Example

Consider the following knowledge base.

Facts
parent(ram, sita).
parent(sita, ravi).
parent(ram, mohan).
Rule
grandparent(X, Z) :- parent(X, Y), parent(Y, Z).
Query
grandparent(ram, ravi).

The system performs reasoning:

parent(ram, sita)

and

parent(sita, ravi)

Therefore:

grandparent(ram, ravi)

So the answer is:

True.

4. Prolog

The most commonly discussed language for logic programming is Prolog.

Prolog = PROgramming in LOGic

Prolog is widely used for demonstrating:

Knowledge representation
Logical reasoning
Rule-based systems
Expert systems
Natural language processing
Automated reasoning

A Prolog program consists mainly of:

Facts + Rules + Queries

5. Prolog Example
% Facts
male(ram).
female(sita).
parent(ram, sita).

% Rule
father(X, Y) :- male(X), parent(X, Y).

Query:

father(ram, sita).

Result:

true

Query:

father(X, sita).

Result:

X = ram
6. How Logic Programming Works

Suppose we have:

human(socrates).

mortal(X) :- human(X).

Query:

mortal(socrates).

The inference process is:

Step 1: Search for mortal(socrates)

The system finds the rule:

mortal(X) :- human(X).
Step 2: Substitute
$$ X = Socrates $$

The rule becomes:

human(socrates)
Step 3: Check the knowledge base

We have:

human(socrates).

Therefore:

mortal(socrates)

is true.

7. Important Concepts in Logic Programming
A. Unification

Unification is the process of finding substitutions that make two logical expressions identical.

Example:

student(X)

and

student(ravi)

can be unified by:

$$ X = Ravi $$
B. Inference

The system derives new information from existing facts and rules.

Example:

$$ Human(Socrates) $$ $$ Human(x) \rightarrow Mortal(x) $$

Therefore:

$$ Mortal(Socrates) $$
C. Backtracking

If the system cannot find a solution through one path, it goes back and tries another possible path.

This is called backtracking.

For example:

A → B → C

If C does not satisfy the query, the system can go back and try another alternative.

D. Resolution

Resolution is a fundamental inference technique used in automated reasoning and is closely associated with the theoretical foundations of Prolog.

It allows logical clauses to be combined to derive conclusions.

8. Logic Programming vs Procedural Programming
Logic Programming	Procedural Programming
Describes what is true	Describes how to perform a task
Uses facts and rules	Uses instructions/statements
Uses inference	Uses explicit control flow
Variables represent logical variables	Variables store values
Automatic search is common	Programmer controls execution
Example: Prolog	Example: C, Java, Python
Example

Procedural approach:

First do A, then do B, then do C.

Logic programming approach:

These facts and rules are true. Find whether the query can be logically derived.

9. Logic Programming and Predicate Logic

These two topics are closely related but not the same.

Predicate Logic

Predicate logic is primarily a formal language for representing knowledge and reasoning.

Example:

$$ \forall x(Human(x) \rightarrow Mortal(x)) $$
Logic Programming

Logic programming uses logical statements in a programming framework.

Example:

mortal(X) :- human(X).

The Prolog rule corresponds approximately to:

$$ Human(X) \rightarrow Mortal(X) $$

So:

$$ \boxed{\text{Predicate Logic = Representation and Reasoning}} $$ $$ \boxed{\text{Logic Programming = Programming using Logic}} $$

Predicate Logic Symbols — Explanation

Predicate Logic, especially First-Order Predicate Logic (FOL), uses symbols to represent objects, properties, relationships, quantities, and logical connections.

A useful way to learn it is to divide the symbols into 6 groups:

1. Constants

A constant represents a specific object or individual.

Common notation:

$$ a,\ b,\ c $$

or meaningful names such as:

$$ Ram,\ Sita,\ Socrates $$
Example
$$ Student(Ram) $$

Meaning:

Ram is a student.

Here, Ram is a constant.

2. Variables

Variables represent an unspecified or arbitrary object.

Common symbols:

$$ x,\ y,\ z $$
Example
$$ Student(x) $$

Meaning:

x is a student.

The value of x can change depending on the situation.

3. Predicates

A predicate represents a property or relationship.

Predicates are usually written with capital letters in mathematical notation.

Unary predicate
$$ Student(x) $$

Meaning:

x is a student.

It has one argument.

Binary predicate
$$ Likes(x,y) $$

Meaning:

x likes y.

It has two arguments.

Ternary predicate
$$ Gives(x,y,z) $$

Meaning:

x gives y to z.

It has three arguments.

Important point

The number of arguments determines the arity of the predicate.

Predicate	Arity	Meaning
Student(x)	1	x is a student
Likes(x,y)	2	x likes y
Gives(x,y,z)	3	x gives y to z
4. Quantifiers

Quantifiers specify how many objects a statement applies to.

There are two fundamental quantifiers.

A. Universal Quantifier — ∀

Symbol:

$$ \boxed{\forall} $$

Read as:

For all
For every

Example
$$ \forall x\ Student(x) $$

Meaning:

Every x is a student.

More commonly, we use it with an implication:

$$ \forall x(Student(x) \rightarrow Intelligent(x)) $$

Meaning:

Every student is intelligent.

The ∀x tells us that the rule applies to every x.

B. Existential Quantifier — ∃

Symbol:

$$ \boxed{\exists} $$

Read as:

There exists
There is at least one

Example
$$ \exists x\ Student(x) $$

Meaning:

There is at least one student.

Another example:

$$ \exists x(Student(x) \land Intelligent(x)) $$

Meaning:

There is at least one student who is intelligent.

5. Logical Connectives

Logical connectives combine predicates and statements.

A. AND — ∧

Symbol:

$$ \boxed{\land} $$

Read as:

AND

Example:

$$ Student(x) \land Intelligent(x) $$

Meaning:

x is a student and x is intelligent.

B. OR — ∨

Symbol:

$$ \boxed{\lor} $$

Read as:

OR

Example:

$$ Student(x) \lor Teacher(x) $$

Meaning:

x is a student or x is a teacher.

C. NOT — ¬

Symbol:

$$ \boxed{\neg} $$

Read as:

NOT

Example:

$$ \neg Student(x) $$

Meaning:

x is not a student.

D. IMPLICATION — →

Symbol:

$$ \boxed{\rightarrow} $$

Read as:

If...then

Example:

$$ Student(x) \rightarrow Studies(x) $$

Meaning:

If x is a student, then x studies.

This is extremely important in AI knowledge representation.

Example
$$ Human(x) \rightarrow Mortal(x) $$

Meaning:

If x is a human, then x is mortal.

E. Biconditional — ↔

Symbol:

$$ \boxed{\leftrightarrow} $$

Read as:

If and only if

Example:

$$ Student(x) \leftrightarrow Learner(x) $$

Meaning:

x is a student if and only if x is a learner.

It represents implication in both directions:

$$ Student(x) \rightarrow Learner(x) $$

and

$$ Learner(x) \rightarrow Student(x) $$
6. Equality Symbol

Symbol:

$$ \boxed{=} $$

It means two terms represent the same object.

Example:

$$ Father(Ram) = Parent(Ram) $$

In formal first-order logic, equality is generally used to state that two terms refer to the same object.

How to Read a Complete Predicate Logic Statement

Consider:

$$ \boxed{\forall x(Student(x) \rightarrow Studies(x))} $$

Read it from outside to inside:

Step 1 — ∀x

For every x

Step 2 — Student(x)

x is a student

Step 3 — →

implies / if...then

Step 4 — Studies(x)

x studies

Complete meaning:

For every x, if x is a student, then x studies.

Example with Both Quantifiers

Consider:

$$ \boxed{\forall x(Student(x) \rightarrow \exists y(Teacher(y) \land Teaches(y,x)))} $$

Break it down:

∀x

For every x

Student(x)

x is a student

→

If...

∃y

there exists some y

Teacher(y)

y is a teacher

∧

and

Teaches(y,x)

y teaches x

Complete meaning

Every student is taught by at least one teacher.

Most Important Symbols for AI Exams

If you are learning Knowledge Representation / Predicate Logic for AI, focus especially on:

$$ \boxed{\forall,\ \exists,\ \land,\ \lor,\ \neg,\ \rightarrow,\ \leftrightarrow} $$

Remember:

∀ = All

∃ = Some

∧ = And

∨ = Or

¬ = Not

→ = If...then

↔ = If and only if

A useful shortcut:

∀ talks about everybody; ∃ talks about at least one.
